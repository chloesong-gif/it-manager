초기 설정

Google 로그인을 사용하려면
Google OAuth Client ID를 입력해주세요.

Client ID 발급 방법
1. Google Cloud Console 접속
2. API 및 서비스 → 사용자 인증 정보 → OAuth 2.0 클라이언트 ID 생성
3. 승인된 JavaScript 원본에 이 페이지가 열리는 주소 추가
   예) http://localhost:8080 또는 도메인

⚠️ file:// 에서는 동작하지 않습니다.
터미널에서 npx serve . -p 8080 후
http://localhost:8080 으로 접속하세요.
